# Веса для локального запуска

Папка `models/` содержит пять checkpoint-файлов для полного запуска.
Ранее экспортированные веса скопированы из `Downloads` без удаления оригиналов;
бинарная модель бедра обучена локально. Сверяйте файлы по SHA-256.

| Задача | Имя в `models/` | SHA-256 |
|---|---|---|
| Анатомия: spine / hip / unknown | `anatomy_spine_hip_unknown_efficientnet_b0.pt` | `a0e81d8cd700c9900a7a5a3cbc8050d3755cf0b38996a969ed1f0cb9a47d2072` |
| Предполагаемый артефакт позвоночника | `spine_artifact_densenet121.pt` | `ba771f8a5fb9f9973af8fa7cfb7227648cdf98f2cd6514eabae9f06c48d08001` |
| Приоритет проверки укладки позвоночника | `spine_positioning_efficientnet_b0.pt` | `1a9b4a7284e16daae9a2d5e4a83b0ae37d06970b0279c1d73faf051478d63b67` |
| Приоритет проверки укладки бедра (кандидат) | `hip_positioning_densenet121_candidate.pt` | `9d46c3ea61c183bc9b441e8c6398d6b4668e4432a4f41518e0198043fac869dd` |
| Качество бедра 0/1 (кандидат) | `hip_binary_candidate.pt` | `cf5ffb4efe247f7e3cc313ac439072444461a59bb6ae287e612b2383846caf40` |

Папка `models/` попадает в Git через Git LFS и копируется в Docker-образ.
После клонирования выполните `git lfs pull`; Docker-сборка отвергнет короткие
LFS-ссылки вместо настоящих файлов. Не публикуйте репозиторий или образ
без проверки прав на исходные данные и условия распространения. Ни один
checkpoint не является
подтверждённой медицинской системой.

Checkpoint укладки бедра содержит замороженную ImageNet-DenseNet121,
логистическую голову, параметры стандартизации и порог 0,02282018.
DenseNet **не** дообучалась. Голову обучали на 127 снимках с однозначно
сопоставленной меткой укладки, включая 25 ошибок. Порог выбрали на OOF
разработочного набора; независимой проверки не было. Подключение этого
файла добавляет только приоритет ручной проверки укладки. Отдельной метки
ротации в Excel нет; она входит в критерий укладки. Отдельная причина ROI
автоматически не определяется.

`hip_binary_candidate.pt` выдаёт предварительное итоговое качество бедра 0/1.
Он обучен на 116 изображениях, для которых ответы обеих сторон в Excel
совпадают. На внефолдовой проверке при чувствительном пороге: 24 TP, 2 FN,
59 FP, 31 TN. Подробности — в `HIP_BINARY_MODEL.md`. Это не независимая
клиническая проверка.
